# Worldwide delivery configuration

## Dream Editions

Dream Editions use a live Prodigi quote for the selected destination. The country selector follows Stripe Checkout's supported shipping country codes. A destination is accepted only when Prodigi returns a valid live route and amount. If no route is returned, checkout remains unavailable for that destination.

## Collector Editions

Collector Editions use customer-facing fixed delivery charges based on the current theprintspace regional schedule plus a modest payment and operating allowance.

| Region | Customer charge |
| --- | ---: |
| United Kingdom | €9 |
| Germany | €9 |
| Other European Union countries | €19 |
| Norway, Iceland, Liechtenstein, Switzerland | €21 |
| United States | €31 |
| Canada | €44 |
| Australia and New Zealand | €82 |
| Other supported destinations | €82 |

Provider estimates recorded in the order ledger remain region-specific. Import duties or destination taxes not collected at checkout may remain the purchaser's responsibility, as stated in the Terms.
